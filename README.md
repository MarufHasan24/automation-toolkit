# automation-toolkit

A central library for scripts, computational design workflows, environmental analysis, BIM automation, and CAD productivity.

## Repository Structure

- `Rhino/Python/` — Python scripts for Rhino automation workflows.
- `Grasshopper/Definitions/` — Reusable Grasshopper definitions.
- `Grasshopper/CSharp/` — C# scripts for Grasshopper components.
- `Grasshopper/Python/` — Python scripts for Grasshopper components.
- `Environmental-Analysis/Honeybee/` — Honeybee analysis assets.
- `Environmental-Analysis/Ladybug/` — Ladybug analysis assets.
- `Environmental-Analysis/Energy-Analysis/` — Energy analysis resources.
- `Revit-Dynamo/Graphs/` — Dynamo graph files for Revit automation.
- `Revit-Dynamo/Python/` — Python scripts used in Dynamo/Revit workflows.
- `AutoCAD/AutoLISP/` — AutoLISP routines for AutoCAD.
- `AutoCAD/Scripts/` — AutoCAD script files for repetitive tasks.
- `Blender/Python/` — Python scripts for Blender automation.
- `Shared-Utilities/` — Shared helper scripts and utilities.
- `Examples/` — Example resources demonstrating toolkit usage.
