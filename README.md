# Architecture Automation Toolkit

A cross-platform collection of scripts and computational-design workflows for architecture.

## Platforms and topics
- Rhino Python
- Grasshopper definitions, Python, and C#
- Honeybee and Ladybug environmental analysis
- Revit Dynamo
- AutoCAD AutoLISP and scripts
- Blender Python
- Shared utilities and examples

## Repository structure
Each tool folder includes an `example.md` template. Replace the template text with details for your own scripts and workflows.

## Recommended documentation for each tool
1. Purpose
2. Software version and dependencies
3. Inputs and settings
4. How to run
5. Expected output
6. Known limitations

## Safety
Test scripts on copies of your models or drawings before running them on important project files. Review code and dependencies before executing scripts from the repository.
